# Built for mobile

PlayRates is natively a web application. However, I believe a big portion of the target audience would want an application like this accessible on their phone. To achieve this, without creating a native mobile application... _yet_... I made it a high priority to optimise all functionality and interfaces for mobile users. I didn't just want the standard mobile responsiveness, but for mobile users to feel like the site was designed for their device too.

Some examples of how I achieved this include:

- A bottom navigation bar on phones, for easy accessibility of the key pages, and a useful feature that is only normally shipped to native mobile apps.
- Modals open as bottom sheets, instead of condensed desktop popups. This allows for more content to fit, and the thumb sits in the right place for many important actions.
- All hover menus, such as for logging games, replaced with easy-to-press icons and buttons, so mobile users don't miss any functionality.
- Interactive elements optimised for mobile, such as the slider to choose a rating, using a sliding motion to select, instead of a user struggling to tap the small bars.

PlayRates is also a Progressive Web App, so it installs to a mobile home screen and opens and feels like a native app, rather than something that is opened in a browser. This, paired with the optimisations, makes the web application feel indistinguishable from a native mobile application.
